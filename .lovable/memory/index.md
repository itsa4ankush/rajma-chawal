# Project Memory

## Core
Raycast-inspired dark design system. Background near-black blue-tinted #07080a (NEVER pure black). Primary text near-white #f9f9f9. Brand accent Raycast Red #FF6363 used as punctuation only (hero, errors). Interactive accent Raycast Blue ~#55b3ff.
Inter everywhere (display + body + UI), GeistMono/JetBrains Mono for code. Positive letter-spacing +0.2px on body, weight 500 baseline. OpenType: calt, kern, liga, ss03 globally.
Multi-layer macOS-native shadows ALWAYS (outer ring + inset top white highlight + inset bottom dark). Never single-layer flat shadows.
Card surface #101111 with 1px rgba(255,255,255,0.06) border + double-ring shadow, 16px radius.
Pill buttons (86px radius / rounded-full) for primary CTAs; 6px radius for secondary. Hover = opacity 0.6–0.7 transition, NEVER color swap.
Borders are subtle rgba(255,255,255,0.06–0.10) on dark surfaces. Section padding 80–120px vertical.
